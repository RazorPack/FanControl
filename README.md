# FanControl

Нативное SwiftUI-приложение для **Mac mini M4** (проверено на `Mac16,10`, macOS 27): показывает обороты и температуры и даёт ручное управление вентилятором.

Apple не публикует API вентилятора. Приложение читает SMC без привилегий, а запись оборотов идёт через небольшой LaunchDaemon от root.

## Возможности

- Живые обороты вентилятора (на M4 mini один вентилятор, обычно 1000–4900 об/мин)
- Температуры CPU / GPU / NAND / Wi‑Fi
- Профили: Авто, Тихий, Баланс, Нагрузка, Максимум и слайдер
- Возврат управления macOS при выходе, сне и если окно «отвалилось» (~20 с)
- Если CPU ≥ 95 °C, тихий режим поднимается автоматически

## Сборка

Нужны Xcode Command Line Tools:

```bash
make
open dist/FanControl.app
# или
make install   # копия в ~/Applications и запуск
```

Первый раз нажмите **«Разрешить управление вентилятором»** и введите пароль администратора. После этого ручные профили начинают писать `F0Md` / `F0Tg`.

## Снятие сервиса

```bash
sudo launchctl bootout system/ru.fancontrol.helper
sudo rm -f /Library/LaunchDaemons/ru.fancontrol.helper.plist
sudo rm -f /Library/PrivilegedHelperTools/ru.fancontrol.helper
```

Ручное управление охлаждением меняет штатную политику macOS. Не держите минимум на жаре и не обходите нижний предел прошивки.
