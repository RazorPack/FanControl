# MacFanControl

[English](README.md) | [Русский](README.ru.md) | [Беларуская](README.be.md)

Натыўная ўтыліта на SwiftUI для **Mac mini M4**, пратэставаная на `Mac16,10` з macOS 27. Праграма паказвае тэмпературы і абароты вентылятара і дазваляе ўручную рэгуляваць яго хуткасць.

Apple не дае публічнага API для кіравання вентылятарам. Датчыкі SMC чытаюцца без павышаных прывілеяў, а запіс налад выконвае невялікая фонавая служба `LaunchDaemon` з правамі root.

## Магчымасці

- Маніторынг вентылятара ў рэальным часе. У Mac mini M4 адзін вентылятар з прыблізным рабочым дыяпазонам 1 000–4 900 аб/хв.
- Паказанні тэмпературы CPU, GPU, памяці NAND і модуля Wi-Fi.
- Профілі «Аўта», «Ціхі», «Баланс», «Прадукцыйны» і «Максімум», а таксама ручны паўзунок хуткасці.
- Вяртанне кіравання вентылятарам macOS пры закрыцці праграмы або пераходзе Mac у рэжым сну. Калі праграма аварыйна завершыцца, тэрмін дзеяння дазволу helper скончыцца прыкладна праз 20 секунд.
- Абарона ад перагрэву: пры тэмпературы CPU 95 °C і вышэй ціхі рэжым аўтаматычна пераключаецца на прадукцыйны.

## Зборка і ўсталяванне

Для зборкі патрэбны Mac з усталяванымі Xcode Command Line Tools. У каталогу рэпазіторыя выканайце:

```bash
make
open dist/MacFanControl.app
```

Каб стварыць сціснуты вобраз дыска:

```bash
make dmg
```

Вобраз будзе захаваны ў `dist/MacFanControl-macos-arm64.dmg`. Таксама можна ўсталяваць праграму ў `~/Applications` і запусціць яе камандай:

```bash
make install
```

Пры першым запуску націсніце **«Дазволіць кіраванне вентылятарам»** і ўвядзіце пароль адміністратара. Гэта ўсталюе helper, які запісвае значэнні `F0Md` і `F0Tg` у SMC.

## Выдаленне фонавага helper

Каб выдаліць сістэмны helper і яго файлы:

```bash
sudo launchctl bootout system/ru.macfancontrol.helper
sudo rm -f /Library/LaunchDaemons/ru.macfancontrol.helper.plist
sudo rm -f /Library/PrivilegedHelperTools/ru.macfancontrol.helper
sudo rm -f /var/run/macfancontrol.sock
```

> **Бяспека:** ручное кіраванне змяняе стандартную працу сістэмы астуджэння macOS. Не пакідайце мінімальныя абароты пры высокай нагрузцы і не спрабуйце абысці абмежаванні прашыўкі.
