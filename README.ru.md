# MacFanControl

[English](README.md) | [Русский](README.ru.md) | [Беларуская](README.be.md)

Нативная утилита на SwiftUI для **Mac mini M4**, протестированная на `Mac16,10` с macOS 27. Приложение показывает температуры и обороты вентилятора и позволяет вручную управлять его скоростью.

Apple не предоставляет публичный API для управления вентилятором. Датчики SMC читаются без повышенных привилегий, а запись настроек выполняет небольшой фоновый сервис `LaunchDaemon` с правами root.

## Возможности

- Мониторинг вентилятора в реальном времени. В Mac mini M4 один вентилятор с примерным рабочим диапазоном 1 000–4 900 об/мин.
- Показания температуры CPU, GPU, NAND-памяти и модуля Wi-Fi.
- Профили «Авто», «Тихий», «Баланс», «Производительный» и «Максимум», а также ручной ползунок скорости.
- Возврат управления вентилятором macOS при выходе из приложения или переходе Mac в режим сна. Если приложение аварийно завершится, срок действия разрешения helper истечёт примерно через 20 секунд.
- Защита от перегрева: при температуре CPU 95 °C и выше тихий режим автоматически переключается на производительный.

## Сборка и установка

Для сборки нужен Mac с установленными Xcode Command Line Tools. В каталоге репозитория выполните:

```bash
make
open dist/MacFanControl.app
```

Чтобы создать сжатый образ диска:

```bash
make dmg
```

Образ появится по пути `dist/MacFanControl-macos-arm64.dmg`. Также можно установить приложение в `~/Applications` и запустить его командой:

```bash
make install
```

При первом запуске нажмите **«Разрешить управление вентилятором»** и введите пароль администратора. Это установит helper, который записывает значения `F0Md` и `F0Tg` в SMC.

## Удаление фонового helper

Чтобы удалить системный helper и его файлы:

```bash
sudo launchctl bootout system/ru.macfancontrol.helper
sudo rm -f /Library/LaunchDaemons/ru.macfancontrol.helper.plist
sudo rm -f /Library/PrivilegedHelperTools/ru.macfancontrol.helper
sudo rm -f /var/run/macfancontrol.sock
```

> **Безопасность:** ручное управление меняет стандартное поведение охлаждения macOS. Не оставляйте минимальные обороты при высокой нагрузке и не пытайтесь обходить ограничения прошивки.
